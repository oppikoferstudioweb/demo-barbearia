# Viking Blade Barber Club • Barber Shop Model

Modelo demonstrativo de alta conversão desenvolvido para barbearias premium e clubes de cavalheiros.

## Recursos
- **Pré-Agendamento Rápido**: Sistema em etapas integrado direto no site, sem necessidade de banco de dados.
- **Régua Interativa de Etapas**: Navegação dinâmica permitindo ao cliente alterar serviço, barbeiro, data ou turno a qualquer momento.
- **Comanda Estruturada no WhatsApp**: Envio automático de resumo completo da reserva direto para a recepção da barbearia.
- **Design Escuro & Responsivo**: Identidade visual focada no público masculino moderno.
